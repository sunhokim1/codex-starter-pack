# Universal AI Starter 0.4.0

유지 관리 원본은 `distribution/releases/0.4.0/universal-ai-starter/`입니다. 루트·experiments 진입점과 `distribution/manifest.json`은 새 소스로 연결됩니다. 0.3.1·0.3.2·0.3.3 소스와 루트의 기존 ZIP은 보관하며 재생성하지 않습니다. 0.4.0 패키지는 로컬 검토용이며 게시하지 않았습니다.

큰 목표는 Sol `gpt-6.1-sol`이 계획하고 Python controller가 순차 진행합니다. 구현마다 Rev가 Luna `gpt-6-luna` 또는 Sol을 선택하며 작은 요청은 계획 호출 없이 시작합니다. 실행 override는 Rev를 우회합니다. 계획 모델은 실행 모델을 고정하지 않습니다. 앱 대화 모델, CLI 요청 모델, backend가 확인한 실제 모델은 별개입니다. 유료 분류·비교 평가·하위 에이전트는 사용하지 않습니다.

[Rev 런타임 안내](assets/rev/README.md), [순차 실행 안내](assets/runner/README.md), [이전 안내](MIGRATION.md)를 확인하세요. 점수는 선택지 확률이며 코딩 성공 확률이 아닙니다. 비교 평가를 수행하지 않았으므로 정책은 보수적인 잠정 정책입니다. 오류·시간 초과·과대 입력은 중단하며 유료 분류나 자동 fallback을 실행하지 않습니다. 필수 검증 subprocess 근거가 있어야 완료합니다.

새 템플릿은 프로젝트 사실과 검증 명령이 미설정입니다. 소스·클라이언트는 `.ai/starter-source/`에 자동 설치·업데이트하고 `.ai/source-install.json`에 버전·해시를 기록합니다. 기존 프로젝트 템플릿은 누락 파일만 복사하며 실제 사실·사용자 모델·routing·검증 설정을 덮어쓰지 않습니다. 이전 형식의 설정은 명시적으로 검토해야 하며 자동 변환하지 않습니다.

실패 복구는 원인과 부분 수정에 대한 명시적 재개 검토 후 제한적으로 진행합니다. 환경·일시 오류는 승격하지 않으며, 확인된 역량 실패만 설정 순서로 승격합니다. 사용자 실행 override는 자동 승격을 막습니다. 확인된 구조 변경만 Sol 재계획 제안을 만들며, 별도 수락 전에는 실행하지 않습니다. 완료 이력·승인·전체 예산을 보존합니다. 자세한 입력 계약은 [순차 실행 안내](assets/runner/README.md)를 확인하세요.

현재 Windows 11·Intel Iris Xe·CUDA 없음·15.7GiB 총 메모리/1.9GiB 가용 환경에서는 모델 다운로드·로드·실제 추론을 실행하지 않습니다. 소스·클라이언트 자동 설치/업데이트는 Rev 자원 부족과 독립적입니다. CPU 및 Windows CUDA도 선택할 수 있으며 bf16/fp16/fp32별 메모리 추정과 잠긴 torch의 실제 연산을 확인합니다. 후보 진단 통과는 모델 로드·추론 성공을 보장하지 않습니다. fixture 검사는 계약을 검증하며 실제 Windows 설치·인증 readiness·추론·성능을 증명하지 않습니다. 의존성 환경 lock 완성과 지원 장비의 실제 smoke는 별도 준비가 필요합니다.

기존 SEV 설치와 개인 skill/runtime은 유지합니다. 참조 확인은 지정한 프로젝트 범위만 다루며 다른 프로젝트 사용 여부를 증명할 수 없습니다. 삭제하지 않습니다. 구 상태와 완료 기록은 원래 runtime으로 읽고 보고서를 보존한 뒤 명시적으로 검토·보관하세요. 완료 작업을 새 계획으로 자동 재실행하지 않습니다.
