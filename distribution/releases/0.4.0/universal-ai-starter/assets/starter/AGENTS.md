# 프로젝트 작업 지침
프로젝트 사실은 PROJECT.md에서 확인한다. 큰 목표는 gpt-6.1-sol로 계획하고 Python controller가 순차 실행한다. 각 구현은 명시적 사용자 override가 없으면 로컬 Rev로 worker(gpt-6-luna) 또는 main(gpt-6.1-sol)을 선택한다. planning_model은 실행 override가 아니다. 유료 분류·하위 에이전트·자동 병렬 실행·비교 평가는 사용하지 않는다.
연결은 .ai/rev.json이고 기존 .ai/sev.json은 자동 이전하지 않는다. 상태·사용자 설정·완료 기록은 보존한다. 모델 성공만으로 완료하지 않고 실제 구성된 검증 근거를 요구한다. 오류·시간 초과·과대 입력은 중단하고 복구 원인을 보고한다. README는 한국어로 작성한다.
소스·클라이언트 자동 설치/업데이트는 실행 연결·모델 환경 준비·실제 추론과 별개다. 기존 사용자 지침·설정·연결·완료 기록을 보존하며 호환되지 않는 실행 상태는 명시적으로 검토하고 자동 재생하지 않는다. Windows/CPU를 일괄 거부하지 않으며 선택 device/dtype의 메모리와 실제 의존성 capability를 검사한다. 후보 진단은 추론 성공이 아니다.
