# Project

## 유형
미초기화.

## 목표와 사용자
미초기화. 사용자가 제공한 목표와 실제 대상 사용자를 확인한 뒤 기록한다.

## 기술 스택·실행 환경
미초기화. 실제 manifest·설정·진입점으로 확인한 내용만 기록한다.

## 아키텍처
미초기화. 존재하는 주요 subsystem과 인터페이스만 기록한다.

## 실행·검증
미초기화. 실제 프로젝트의 실행 방법을 확인한 뒤 기록하고, 확인한 검증 명령은 `.ai/verification.yaml`에 설정한다. 명령을 기록했다고 실행·통과한 것은 아니다.

## 제약
기존 프로젝트 사실·사용자 변경·모델 선택·검증 명령을 보존한다. 비밀값을 이 파일에 저장하지 않는다. 확인되지 않은 프레임워크·게임·제품 요구를 넣지 않는다.
