# Desktop preset

선택 사항을 `PROJECT.md`에 기록한다. 특정 toolkit/runtime을 강제하지 않는다.

- Target OS와 지원 버전
- UI toolkit / runtime
- Window lifecycle, navigation, system tray 여부
- Local storage와 파일 접근
- Backend/networking 여부
- OS integration, permissions, sandbox 요구사항
- Packaging, distribution, update 전략
- Input, accessibility, 화면 크기 대응
- Testing strategy와 주요 사용자 flow

선택 후 application/platform 경계와 tests를 map에 기록하고 검증 명령을 설정한다.
