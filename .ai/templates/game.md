# Game preset

선택 사항을 `PROJECT.md`에 기록한다. 특정 engine을 강제하지 않는다.

- Engine
- 2D / 3D
- Target platform
- Rendering과 성능 예산
- Input과 제어 방식
- Save system
- Asset pipeline
- Game state와 주요 gameplay 경계
- Testing/debugging strategy와 플레이 검증 기준
- Networking 여부와 multiplayer 요구사항

선택 후 gameplay/assets/tests 진입점을 map에 기록하고 검증 명령을 설정한다.
