# Web / SaaS preset

선택 사항을 `PROJECT.md`에 기록한다. 특정 framework를 기본값으로 강제하지 않는다.

- Frontend framework 또는 framework 없이 구현할지
- Backend 여부와 서비스 경계
- Database 여부와 데이터 요구사항
- Authentication 및 권한
- Deployment target
- Design system과 디자인 source of truth
- Testing strategy와 acceptance criteria
- Browser support, responsive states, 접근성
- SaaS인 경우 tenant 분리, 결제, 운영 요구사항

선택 후 application 구조, verification 명령, repository map을 초기화한다.
