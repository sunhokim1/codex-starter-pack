# Mobile preset

선택 사항을 `PROJECT.md`에 기록한다. 특정 framework를 강제하지 않는다.

- Native / cross-platform
- Target OS 및 지원 버전
- Navigation
- Local storage와 offline/sync
- Backend
- Push notifications 여부
- Permissions와 개인정보 요구사항
- Testing: device, simulator, 주요 사용자 flow
- 배포 방식과 responsive/accessibility 상태

선택 후 application 구조와 플랫폼별 검증 명령, repository map을 초기화한다.
