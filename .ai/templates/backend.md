# Backend / API preset

선택 사항을 `PROJECT.md`에 기록한다. 특정 언어나 framework를 강제하지 않는다.

- Language / runtime / framework
- API protocol과 public contract
- Service boundaries
- Database/storage 여부와 schema/migration 전략
- Authentication / authorization
- External integrations 및 background jobs 여부
- Error handling, observability, 성능 요구사항
- Deployment target와 운영 제약
- Unit/integration/contract/acceptance testing 전략

선택 후 service/schema/tests 진입점을 map에 기록하고 verification 명령을 설정한다.
